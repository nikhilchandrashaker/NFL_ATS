Can a model beat the NFL closing line?

Four models were trained only on past seasons, then asked to pick the side of the point spread in each game of 2015–2025. A bettor needs to win 52.38% of bets at -110 to break even. Everything below recalculates live from the 2,937 graded test games and the 1979–2025 history.

Walk-forward test: cover rate by strategy

Dot = share of bets that covered. Whisker = 95% Wilson interval. Yellow line = break-even at -110.

Predicted vs actual margin

Test games grouped by predicted home margin. A model with real edge would sit visibly off the market's points, closer to the diagonal where predicted equals actual.

  • The file has one spread column per game and no moneylines or opening lines, so the spread is treated as the closing line without verification. Spreads before 1979 are excluded from modeling and from this dashboard.
  • Weather is the conditions recorded for the game, not a pre-game forecast. Temperature and wind are missing for most outdoor games in 2019–2024, so weather slices are thin in the test period.
  • Filtering many ways and reading the best result is how false edges get found. With a dozen or more looks, a single result needs p below about 0.004 to count.
  • p-values here use a normal approximation; the report uses exact binomial tests.
